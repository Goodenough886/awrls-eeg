## 统计与解释边界

`paired_statistics.csv` 提供配对 Wilcoxon（Pratt）、5,000 次单位级 bootstrap 与 Holm 校正。公共测试先对同一源对的六 SNR 平均；真实数据以 13 名受试者为单位；种子不当作独立样本。内部 300 段仍是历史开发数据，公共片段独立也不等于受试者独立。

这次基线扩展发生在既有结果查看之后，应称为补充分析；不能追溯为最初预注册。没有因结果好坏筛选会话或种子，没有追加下游实验。

## 执行与可复现性

Claude 原脚本保留为 `claude_frozen_baselines_original.py`。新执行器分开试跑、完整公共测试、完整 Kaya 和新增会话，按单条任务保存进度，避免试跑后跳过剩余样本或将前 30 秒当作全长完成。

MCA/FBSE 和公共、内部对照使用原 NumPy 实现。Kaya OVME 使用经过数值一致性核验的 FP64 编译迭代核：参数、迭代预算、停止条件、HHO 随机数、检测及回归规则不变；浮点归约顺序及代数等价的复数平方模计算存在舍入差异，因此附片段及完整块的验证结果，不宣称所有输入逐位一致。中途的缓冲区复用逐位等价；后续平方模提速保留了切换前全部检查点的哈希，并附与原 NumPy 计算块的误差核验。加速验证未通过的结果不会进入本包。

新波形按 float32 存储，指标在存储前以 float64 计算，每条保留存储误差和哈希。并发耗时仅供执行记录，不替代原论文独立运行时间测量；断点续跑记录中的 compute_s 可能仅包含最后一次执行的耗时，不能作为完整算法速度比较。
